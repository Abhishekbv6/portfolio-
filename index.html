About

From spreadsheets to systems that reason

I work as a Data Analyst while completing an MCA, and the two feed each other constantly — coursework gives me the theory, day-to-day analyst work gives me the mess of real data to test it on. I'm most at home somewhere between a clean dashboard and a messy dataset that hasn't decided what it wants to say yet.

My core work is analytics and machine learning: segmentation, churn models, demand forecasting. More recently I've been moving deliberately toward AI engineering — building systems where a language model doesn't just answer a question but plans, calls tools, and completes a task end to end.

I mapped out a 12-phase agentic AI roadmap for myself, from Python and math foundations through multi-agent systems and deployment, and I'm working through it in order. I build the agent loop by hand before reaching for a framework, and treat Pydantic and async as non-negotiable rather than optional — the goal is to actually understand what a framework like LangGraph is doing underneath, not just call it.

01

AI Candidate Screening Agent

An agentic AI system that reads a job requirement, reasons over candidate profiles against it, and screens them autonomously — not a single prompt-and-response, but a planning agent built on LangGraph with Gemini as the reasoning engine. It decides which candidates to shortlist and why, and exposes the whole flow through a Gradio interface so a non-technical user can run it without touching code.
